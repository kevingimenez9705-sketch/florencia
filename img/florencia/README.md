# Foto de Florencia

Colocá acá la foto de Florencia Contrafatti con el nombre:

```
foto.jpg
```

(también funciona `.jpeg` o `.png`, pero en ese caso hay que ajustar la
extensión en el atributo `src` de la etiqueta `<img>` dentro de `index.html`,
en la sección `Miembro del equipo`).

Mientras no haya ninguna imagen en esta carpeta, el panel muestra un
ícono de placeholder en su lugar.
